"My Profile" and "Game Details" set to "Public": Required for achievement tracking.
Steam app > User icon (top-right) > View My Profile > Edit Profile > Privacy Settings

Steam status set to "Online": Required to detect launched games.
Steam app > Friends > Online


BEHAVIOR

Runtime data files are stored in:
- @Resources\Cache\Data\

playtime_2weeks.json
- Built first when the skin starts.
- Uses GetRecentlyPlayedGames.
- Sorted by playtime_2weeks descending.

PlayedGames.json
- Contains 0 to 10 items.
- Checked every 15 seconds.
- If GetPlayerSummaries has no gameid, no change.
- If gameid equals the top item, its LastPlayedUtc is refreshed.
- Otherwise:
  1. Remove any older copy of that AppId.
  2. Insert the active game at the top.
  3. Keep only the first 10 items.

DISPLAY
- Startup is sequential:
  1. Build playtime_2weeks.json
  2. Update PlayedGames.json from the current active game
  3. Check recent achievements from the tracked games
  4. Rebuild the visible display
- PlayedGames.json is used first, but only entries newer than the selected Recently played expiration are processed.
- Empty slots are filled from playtime_2weeks.json.
- Duplicate AppIds are skipped.
- During polling, the display is rebuilt only when the active game actually changes.
- During polling, the display is also rebuilt when a PlayedGames.json entry ages out of the selected Recently played expiration window.
- Recent achievements are checked once per minute with GetPlayerAchievements.
- Only achievements unlocked within the selected Recent achievement expiration are shown.
- Achievement display names and icons come from GetSchemaForGame and are cached locally.
- Recent achievement groups are rendered as cached images at the bottom of the skin.
- If Steam is offline, the skin keeps using the last saved PlayedGames.json, playtime_2weeks.json, and cached images instead of clearing the display.
- While offline, a "No internet conection" bar is shown and clicking it forces an immediate retry.
- Offline state is rechecked every 15 seconds by the normal polling measure.
- When the connection comes back, the skin automatically clears the offline bar and refreshes playtime_2weeks.json once.
- If cover art download fails, the slot falls back to the text tile instead of failing the whole rebuild.
- Custom skin actions include:
  - Settings
  - Rebuild

LOG
